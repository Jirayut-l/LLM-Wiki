# Context Window (Claude Code)

The **Context Window** in an agentic coding environment like Claude Code holds the entire conversation, every file read, and every command output. Performance degrades as the context fills up, making aggressive context management (such as clearing history, summarizing via compacting, or delegating tasks to subagents) the most critical aspect of using the tool effectively.
