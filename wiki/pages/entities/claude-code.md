# Claude Code

**Claude Code** is an agentic coding environment created by Anthropic. Unlike traditional conversational chatbots, it operates directly within the developer's environment, capable of reading files, executing commands, making codebase changes, and autonomously working through complex problems.

It utilizes a context window that includes the conversation history, read files, and command outputs, making context management a critical aspect of its effective use. It supports various extensions such as Skills, Hooks, Subagents, and MCP Servers to enhance its capabilities deterministically.
