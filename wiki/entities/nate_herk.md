# Nate Herk

## Overview
Nate Herk คือผู้เชี่ยวชาญและผู้สร้างคอนเทนต์ด้าน AI Automation เขาเป็นผู้ก่อตั้งคอมมูนิตี้ AI Automation Society และเป็นผู้จัดทำคอร์สเรียนฟรีด้าน AI OS บนแพลตฟอร์ม Skool นอกจากนี้เขายังจัดรายการพอดแคสต์บน YouTube และให้บริการต่างๆ ผ่าน UppIt AI

## Key Characteristics
- **การสร้างชุมชนและการศึกษา**: ก่อตั้ง AI Automation Society เพื่อเป็นแหล่งเรียนรู้ โดยมีคอร์สฟรีและแบบพรีเมียม (AI Automation Society Plus) ที่ให้การสนับสนุนแบบไม่จำกัด
- **การสร้างเนื้อหา**: ผลิตวิดีโอให้ความรู้เกี่ยวกับการใช้งาน AI บนช่อง YouTube และมีพอดแคสต์เป็นของตนเอง
- **การพัฒนาเครื่องมือ**: สร้างและแจกจ่ายเครื่องมือที่มีประโยชน์ เช่น Free Token Dashboard และ Session Handoff skill สำหรับผู้ใช้งาน Claude Code ให้กับสมาชิกในชุมชน
- **บริการและธุรกิจ**: ดำเนินธุรกิจและให้บริการผ่านแพลตฟอร์ม uppitai.com
